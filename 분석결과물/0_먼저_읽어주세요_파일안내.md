# 졸업작품 분석 결과물 — 파일 안내 (먼저 읽어주세요)

코딩 문제 풀이 이력 분석과 LLM을 활용한 맞춤형 학습 지원 시스템의 분석 결과물입니다.
모든 결과는 `usersCodeforcesSubmissionsEnd2024 (2).csv`(제출 17,607,999건) 실제 데이터로 노트북을 끝까지 실행해 만들었습니다.

**결과 대시보드 (웹에서 보기)**: https://claude.ai/artifact/75cBh8V8TngdjxrYkHambx
(다른 사람이 이 링크를 열려면, 만든 사람이 대시보드 화면의 공유 메뉴에서 먼저 공유해야 합니다.)

## LLM 학습 도우미 앱 여는 법 (더블클릭 한 번)
| 컴퓨터 | 더블클릭할 파일 (이 폴더 맨 위) |
|---|---|
| 맥 | `LLM앱_실행_맥.command` |
| 윈도우 | `LLM앱_실행_윈도우.bat` |

- 처음 한 번은 필요한 패키지를 자동으로 설치해요(1~3분). 그다음부터는 바로 열려요.
- 브라우저에 앱이 열리면 그대로 쓰면 되고, 다 쓴 뒤에는 검은 창(터미널)을 닫으면 앱이 꺼져요.
- 파이썬이 없다면 python.org에서 설치하세요. **윈도우는 설치 첫 화면에서 "Add python.exe to PATH"에 꼭 체크**해야 해요.
- 맥에서 "확인되지 않은 개발자" 경고가 뜨면: 파일을 오른쪽 클릭 → 열기 → 열기.
- 윈도우에서 "Windows의 PC 보호" 파란 창이 뜨면: 추가 정보 → 실행.
- API 키가 없어도 미리 만들어 둔 AI 결과(user5060)와 진단 화면은 다 보여요. AI 버튼까지 쓰려면 앱 폴더의 `env_예시.txt`를 보고 `.env` 파일을 만드세요.

## Colab에서 직접 실행하기
1. colab.research.google.com → 파일 → 노트북 업로드 → `1_분석코드_Colab용.ipynb`
2. 런타임 → **모두 실행**. 따로 올릴 파일은 없다.
   - 데이터는 원본 출처(HuggingFace)에서 자동으로 내려받는다. 팀이 가진 CSV와 완전히 같은 파일이다(SHA-256 동일).
   - 문제정보는 Codeforces 공식 API에서 자동으로 내려받는다. 이 폴더의 결과와 똑같이 맞추려면 실행 전에 왼쪽 파일 창의 `/content/cf_project/`에 `문제정보_Codeforces.json`을 올린다.
3. 끝나면 마지막 셀이 `분석결과.zip`(위 `분석결과/` 폴더 전체)을 내려받는다.
4. 실행 결과가 담긴 노트북은 파일 → 다운로드 → .ipynb 다운로드로 저장한다.
5. 구글 드라이브에 저장하고 싶으면 0절의 `USE_DRIVE = False`를 `True`로 바꾼다.

참고:
- 맥(메모리 18GB)에서 전체 실행에 약 13분이 걸렸다. **Colab에서는 아직 직접 돌려 보지 않았다.**
- 메모리가 부족하면 런타임 → 런타임 유형 변경에서 높은 RAM을 고른다.
