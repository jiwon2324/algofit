# 알고핏(AlgoFit) (Streamlit + LLM) — 실행 방법

**학습자(사용자)가 직접 보고 쓰는 앱**입니다. 학습자가 자기 Codeforces 아이디를 넣으면
내 약한 유형·잘하는 유형, 분야별·난이도별 풀이, 풀이 습관을 쉬운 말로 보여 주고,
AI 코치가 설명과 2주 학습 계획을 만들어 주며, 막힌 문제는 정답 코드 없이 힌트를 줍니다.

캡스톤 디자인 실습(2학기) 수업 예제(1~7주차, LLM5~LLM9)에서 배운 방법으로 만들었고,
분석 노트북(8절)이 만든 `분석결과/웹LLM용_사용자별_진단.jsonl`(사용자 8,507명의 실제 진단)을 읽어서 씁니다.

## 화면 구성
| 위치 | 학습자가 보는 것 |
|---|---|
| 왼쪽 사이드바 | Codeforces 아이디 입력(체험용 `user12313`이 미리 들어 있음), 이름(선택) |
| 맨 위 | "OO님의 학습 리포트" — 진단 기간, 학습 유형과 설명 |
| 📊 내 학습 리포트 | 실력 점수(공식 레이팅) · 평소 실력(실효 레이팅) · 전체 판정 · 보완 필요/잘하는 분야 수 → 분야 카드("163문제 도전해서 143문제 맞혔어요 · 내 평소 실력이면 약 150.2문제 → 5% 적게") → 분야별 막대그래프 → 난이도별 표 → 풀이 습관 → **AI 코치 설명 · 맞춤 지도 방향(무엇을 / 어느 수준에서 / 어떻게) · 2주 학습 계획** → **학습 리포트 저장하기(Word)** |
| 💬 문제 풀이 도움 | Claude처럼 **왼쪽 메뉴**: 맨 위 [내 학습 리포트] → [+ 새로 만들기] → 최근 문제 목록(3개 이상이면 검색), 맨 아래 내 아이디·이름. [새로 만들기] → 문제 이름·분야·난이도·문제·내 코드 입력(캡처 이미지로도 가능) → **저장하고 질문 시작** → 아래 입력칸에서 계속 질문. 답변이 글자 단위로 바로 나옴(스트리밍), 추천 질문 버튼, **다시 답변 받기**, **👍👎 답변 평가**, **해결했어요(✓)**, **대화 내보내기(.md)**, 목록 옆 **⋯ 메뉴(이름 바꾸기·해결 표시·대화 내용 지우기·문제 삭제)**, 맨 위 검색. 진단 결과로 **추천 도움 정도(조금씩 / 보통 / 많이)**. 문제와 관계없는 질문·의미 없는 입력·정답 코드 요구에는 힌트를 주지 않고 안내. 저장한 문제는 `대화기록/아이디.json`에 남음 |

학습자 화면이므로 어려운 말은 화면·Word 리포트·AI 답변 모두에서 쉬운 말로 바꿨습니다. (AI에게도 같은 규칙을 지시)

| 분석 용어 | 학습자 화면 |
|---|---|
| 레이팅 | 실력 점수 (처음 나올 때 "Codeforces 레이팅"이라고 함께 표시) |
| 레이팅 구간 ~1199 / 1200-1399 / 1400-1599 / 1600-1899 / 1900-2099 / 2100+ | 입문 / 초급 / 중급 / 중상급 / 상급 / 최상급 단계 |
| 같은 레이팅 학습자, 기대 대비, z값 | 실력이 비슷한 사람들, "평균보다 ~% 적게/더 많이" |
| 문제 난이도 800-1199 / 1200-1599 / 1600-1999 / 2000-2399 / 2400+ | 쉬움 / 보통 / 어려움 / 매우 어려움 / 최고 난도 (숫자 함께 표시) |
| 시도, 해결, 해결률 | 도전, 맞힘, 맞힌 비율 |
| WA / TLE·MLE / RE / CE | 답이 틀림 / 너무 느리거나 메모리 초과 / 실행하다 멈춤 / 문법 오류 |
| 태그 이름(dp, greedy …) | 한글 이름 + 한 줄 설명 (예: 다이나믹 프로그래밍 — 작은 문제의 답을 저장해 두고 큰 문제를 푸는 방법) |

단계 이름과 난이도 이름은 화면 표시용으로 붙인 이름이고, 분석 결과(구간 경계)는 그대로입니다.
숫자는 모두 진단 파일의 실제 값에서 계산합니다. 예: 비슷한 실력 평균 약 13.5문제 = 맞힘 11 ÷ 기대 대비 0.815

| 4주차 LLM8 면접 도우미 (llm8_1~3.py) | 세션 상태로 결과 유지, `process_text` 방식의 GPT 호출 | 진단 설명·문제별 대화를 세션 상태에 저장(+ 파일로 저장해 다시 켜도 유지), `process_messages` 호출 함수. 음성 녹음은 제외 |
| 7주차 LLM9 이미지 분석 (llm9_1~3_2.py) | `encode_image`, `analyze_image`로 gpt-4o에 이미지(base64) 보내기 | **문제·오류 화면 캡처를 읽어 '문제'칸에 넣기** (같은 함수 이름·구조) |
| 8주차 LLM10 이메일 (llm10_2~3.py) | `response_format={'type':'json_object'}`로 JSON 받기 | **AI 코치 설명·맞춤 지도 방향·2주 계획을 JSON으로 받아 카드로 표시**. 이메일 보내기(smtplib)는 학습자 화면에 필요 없어 제외 |

## 맞춤 지도 방향을 정하는 규칙
AI가 마음대로 정하지 않도록, 지도 방향은 진단 결과에서 규칙으로 정하고 AI는 근거와 구체적인 방법만 덧붙입니다 (`학습도우미_app.py`의 `guidance_rule`).
- **무엇을**: 약점 분야. 약점이 없으면 전체 판정이 '실력 부족'이면 기본기, 아니면 강점을 살려 한 단계 위 도전
- **어느 수준에서**: 평소 실력(실효 레이팅, 계산 불가면 실력 점수)이 속한 난이도 구간. 약점 없이 '레이팅 이상'이면 한 구간 위
- **어떻게**: 학습 유형별 연습 방법 (효율 개선 필요형 → 시간 복잡도 먼저 계산 / 로직 점검형 → 경계값·반례 확인 / 문법 실수·빠른 재제출형 → 로컬 컴파일 후 제출, 원인 적고 재제출 / 도전적 시행착오형 → 도전 유지 + 첫 제출 정답률 높이기)

## 문제 풀이 도움: 진단에 맞춰 힌트 양 조절 (`help_amount_rule`)
어떤 도움 정도든 **개념 설명 + 단계별 힌트**를 주고, 양만 진단 결과로 조절합니다 (못하는 부분은 많이, 잘하는 부분은 조금씩).
1. 시작값: 전체 판정 실력 부족 → 많이 / 레이팅 수준 → 보통 / 레이팅 이상 → 조금씩
2. 문제 분야가 약점이면 한 단계 더 많이, 강점이면 한 단계 더 조금씩
3. 문제 난이도가 평소 실력보다 200점 이상 높으면 한 단계 더 많이, 200점 이상 낮으면 한 단계 더 조금씩
- 조금씩: 개념 한 줄 + 작은 힌트 3개를 [다음 힌트 보기]로 하나씩 / 보통: 접근 방향 + 4단계 핵심 / 많이: 개념 설명과 예시 + 5단계 자세한 풀이

## 앱을 켜자마자 결과가 보이게 (예시결과.json)
- `예시결과.json`에 발표 사례 6명(user12313, user14684, user4864, user10548, user1610, user9513)의 **실제 AI 결과**(gpt-4o-mini로 만든 진단 설명·맞춤 지도 방향·2주 학습 계획)와, 같은 DP 문제를 3명(user1610 '많이', user12313 '보통', user4864 '조금씩')이 물었을 때의 실제 힌트를 문제 목록에 넣어 두었습니다. 사례는 학습 유형마다 '약점이 1개 이상인 사람 중 문제 수가 가장 많은 사람'을 고르고, 진단 그림 사례 2(user1610)와 '레이팅 수준' 1명(user9513)을 더했습니다.
- 앱을 켜면 버튼을 누르지 않아도 이 결과가 학습자 화면에 그대로 나옵니다. API 키가 없어도 발표 시연이 됩니다.
- [AI 코치에게 다시 분석 받기]를 누르거나 문제에 질문하면 그때 새로 만듭니다.
- 예시 결과를 새로 만들려면 `python3 예시결과_만들기.py` (OpenAI API 9회 호출).

## 실행 순서
**더블클릭 한 번이면 돼요.** 맥은 `앱_실행.command`, 윈도우는 `앱_실행_윈도우.bat` (졸업작품 폴더 맨 위의 `LLM앱_실행_맥.command` / `LLM앱_실행_윈도우.bat`도 같아요).
실행 파일이 알아서 하는 일:
1. 파이썬 3.9 이상이 있는지 확인 (없으면 설치 페이지를 열어 줌)
2. 필요한 패키지가 없으면 `requirements.txt`대로 자동 설치 (처음 한 번, 1~3분)
3. 스트림릿 첫 실행 때 이메일을 묻는 질문 건너뛰기
4. 앱 실행 → 브라우저가 자동으로 열림 (안 열리면 창에 나온 Local URL 주소를 브라우저에 입력)

끄려면 검은 창(터미널)을 닫거나 `Ctrl + C`.

- 맥에서 "확인되지 않은 개발자" 경고 → 파일 오른쪽 클릭 → 열기 → 열기
- 윈도우에서 "Windows의 PC 보호" 창 → 추가 정보 → 실행
- 윈도우에 파이썬을 새로 깔 때는 설치 첫 화면에서 **"Add python.exe to PATH"** 체크
