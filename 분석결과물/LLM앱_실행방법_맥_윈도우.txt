==============================================
 알고핏(AlgoFit) — LLM 학습 도우미 실행 방법 (맥 / 윈도우)
==============================================

[처음 한 번만] 파이썬 설치
  - https://www.python.org/downloads/ 에서 Python 3.12 이상 설치
  - 윈도우: 설치 첫 화면 맨 아래 "Add python.exe to PATH" 꼭 체크!
  - 맥: 받은 .pkg 파일 실행해서 설치

----------------------------------------------
 윈도우
----------------------------------------------
1) 6_LLM_학습도우미_앱.zip 을 마우스 오른쪽 클릭 → "모두 압축 풀기"
   (압축 파일을 더블클릭해서 안에서 바로 실행하면 안 돼요. 꼭 압축을 푼 다음 실행!)
2) 풀린 폴더 → 졸업작품_분석_결과물 → LLM앱_실행_윈도우.bat 더블클릭
   - "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행]
   - 처음에는 필요한 프로그램을 자동으로 설치해요 (1~3분)
3) 브라우저가 열리면 끝! (안 열리면 검은 창에 나온 http://localhost:8501 을 주소창에 입력)
4) 끌 때: 검은 창을 닫으면 돼요

----------------------------------------------
 맥
----------------------------------------------
1) 6_LLM_학습도우미_앱.zip 더블클릭 (압축이 풀려요)
2) 졸업작품_분석_결과물 → LLM앱_실행_맥.command 더블클릭
   - "확인되지 않은 개발자" / "열 수 없음" 창이 뜨면:
     [완료] 누른 뒤 → 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 [그래도 열기]
     (또는 파일을 마우스 오른쪽 클릭 → [열기] → [열기])
   - 처음에는 필요한 프로그램을 자동으로 설치해요 (1~3분)
3) 브라우저가 열리면 끝! 끌 때는 터미널 창을 닫으면 돼요

   위 방법이 안 되면 터미널에 아래 두 줄 입력:
     cd ~/Downloads/졸업작품_분석_결과물/6_LLM_학습도우미_스트림릿     (압축 푼 위치에 맞게)
     python3 -m pip install -r requirements.txt && python3 -m streamlit run app.py
